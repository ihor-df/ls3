- Дата релиза сохранена. `sortOrder` и SEO не переносились.

- Папка медиатеки для всех обложек: `version-history`.
  После изменения структуры 68 обложек перенесены из подпапок версий в общую папку,
  68 пустых подпапок удалены. ID, URL, имена файлов и остальные метаданные сохранены.
- Шесть исходных ID документов и три исходных ID групп переводов сохранены.

## Проверки

- Все 612 документов сверены с планом, преобразованным из снимка Strapi.
- При конвертации проверено сохранение текста; списки и выделения преобразованы
  в Portable Text. Изолированные нумерованные заголовки сохраняют свои номера.
- Ответ без токена совпадает с авторизованным ответом для всех 612 документов.
- Все ссылки переводов разрешаются, в каждой группе ровно девять языков.
- Проверены имена файлов, SHA-1 оригиналов, вложенность папок и доступность всех
  68 изображений через CDN.
- Официальная валидация Sanity: 680 документов и групп переводов, без ошибок и
  предупреждений.
- Сверка с Strapi после импорта не обнаружила изменений источника за время переноса.
- Production сборки Studio и сайта прошли. Видимый HTML всех девяти локалей
  содержит актуальные релизы 2026 года, включая `v2.21.0`.
- На опубликованной русской странице подтверждён актуальный HTML. В браузере
  локальной production сборки проверены фильтр 2023 года и поиск `v2.0.0`.
- Путь для новых загрузок и миграций: `version-history`, без подпапок версий.
  Для блога сохраняется структура `blog/<slug>`.

Для отображения нумерованных списков исправлена опечатка `numyer` → `number`

## Резервная копия и воспроизводимость

Скрипты, тесты и снимки завершённой миграции убраны из рабочего дерева.
Локальная резервная копия: `cms/backups/completed-migrations-2026-10-27.tar.gz`
(исключена из Git). Содержимое архива сверено с оригиналами по SHA-256.
Снимок внутри архива: `migrations/version-history/data/2026-10-26T15-10-37.961Z/`.
Он содержит оригиналы обложек, исходные данные,
`sanity-before.json`, план, журнал транзакций и итоговые отчёты
`verification.json`, `html-checks.json`, `schema-validation.ndjson`.
Пустой `schema-validation.ndjson` означает отсутствие замечаний валидатора.
Сохранён и дополнительный снимок перед исправлением ID новых документов.
Перед переносом обложек сохранён `media-before-flatten-2026-10-26T16-09-27.561Z.json`;
результат сверки находится в `media-flatten-verification.json`.

Скрипты и порядок запуска сохранены внутри архива в
`migrations/version-history/README.md`. Для восстановления из каталога `cms/`:

```sh
tar -xzf backups/completed-migrations-2026-10-27.tar.gz migrations/version-history
```

Для повторного запуска скриптов потребуется вернуть dev-зависимость
`@portabletext/markdown@^2.7.1`, удалённую после завершения миграции.

При ошибках CLI выводит только сообщение: полные объекты ошибок SDK могут содержать
заголовки авторизации. Sanity токен, попавший в диагностику сетевой ошибки во время
проверки, следует отозвать и заменить в `landing/.env.local`.
