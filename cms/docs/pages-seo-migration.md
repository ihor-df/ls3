## Резервная копия

Скрипты, тесты и снимки завершённой миграции убраны из рабочего дерева.
Локальная резервная копия: `cms/backups/completed-migrations-2026-10-27.tar.gz`
(исключена из Git). Содержимое архива сверено с оригиналами по SHA-256.
Снимок внутри архива: `migrations/pages-seo/data/2026-10-27T14-16-03.783Z/`.

- `strapi-pages.json` — исходные опубликованные документы с SEO.
- `sanity-before.json`, `sanity-pre-apply.json` — исходное состояние и копия
  непосредственно перед записью.
- `plan.json` — полный план с сохранёнными ID и новыми Sanity UUID.
- `applied-groups.json` — журнал пяти изменившихся групп и одной без изменений.
- `sanity-after.json`, `verification.json` — итоговое состояние и сверка.
- `schema-validation.ndjson` — предупреждения валидатора.
- `html-live/` — HTML всех страниц и результаты проверки метатегов.

Порядок запуска сохранён внутри архива в `migrations/pages-seo/README.md`.
Для восстановления из каталога `cms/`:

```sh
tar -xzf backups/completed-migrations-2026-10-27.tar.gz migrations/pages-seo migrations/version-history/context.mjs
```

Для повторного запуска скриптов потребуется вернуть прямую dev-зависимость
`@sanity/uuid@3.0.3`, удалённую после завершения миграции.

Изменения данных уже доступны в production; пуш кода для них не требуется.
