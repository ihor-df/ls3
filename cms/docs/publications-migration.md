## Данные и изображения

- `title` → `title`, `link` → `url`, `slug` → `slug.current`.
- `publishedAt` сохранён точно из Strapi для каждой локали; исходные даты относятся
  к 23–25 декабря 2025 года и могут различаться между переводами одной публикации.
- Каждая обложка загружена оригинальными байтами WebP, без повторного сжатия.
  Все изображения имеют размер 726×408; контрольные суммы совпадают с экспортом.
- 53 исходных файла содержали 49 уникальных изображений. Совпадающие изображения
  и переводы используют общий Sanity asset.
- Изображения находятся непосредственно в папке `publications`, с читаемыми
  именами `publications-<slug>.webp`.
- `cover.alt` пустой: изображение и полный заголовок находятся в одной ссылке.
  Поле оставлено редактируемым для изображений, передающих дополнительный смысл.

H1, meta title и meta description взяты из HTML соответствующих локализованных
страниц `https://ls.app/.../publications`. Созданы семь отсутствовавших локалей,
обновлены английская и русская страницы; дополнительные существовавшие поля SEO
сохранены.

## Проверки

- Все 477 документов сверены с исходными полями и локализованными датами Strapi.
- Публичные ответы без токена совпадают с авторизованными: 477 публикаций и 9 страниц.
- Во всех 54 группах по девять корректных сильных ссылок на переводы.
- Проверены контрольные суммы, размеры, MIME, имена файлов, папка и 49 URL картинок.
- Незатронутые документы из резервной копии остались без изменений.
- Повторная сверка Strapi подтвердила неизменность одобренного источника.
- Официальный валидатор Sanity проверил 540 документов: ошибок нет. Единственное
  предупреждение — французский meta-description длиной 170 символов при
  рекомендуемых 160; он сохранён дословно из источника.
- На опубликованном сайте проверен видимый HTML всех девяти локалей: первая и
  последняя страницы, карточки, изображения, внешние ссылки, H1 и SEO совпадают
  с импортом. Проверка охватывает все 53 публикации на каждом языке.
- В текущей локальной production сборке проверены страницы с 12 и 53 карточками
  для шести локалей, включая русский визуальный просмотр. Локальные маршруты
  `/publications`, `/ua/publications`, `/ch/publications` возвращали циклический
  307; на опубликованном сайте HTML и пагинация этих локалей прошли проверку.
- Четыре теста преобразования, семь тестов медиатеки, ESLint, TypeScript,
  schema extraction, TypeGen и сборки Studio/сайта прошли.

На опубликованном сайте размер страницы пока равен одной карточке. В рабочей копии
лимит уже изменён пользователем на 12; локальная сборка проверена с этим значением.

## Исходники и резервная копия

Скрипты, тесты и снимки завершённой миграции убраны из рабочего дерева.
Локальная резервная копия: `cms/backups/completed-migrations-2026-10-27.tar.gz`
(исключена из Git). Содержимое архива сверено с оригиналами по SHA-256.
Снимок внутри архива: `migrations/publications/data/2026-10-27T12-51-58.423Z/`.

- `sanity-before.json` — исходное состояние при экспорте.
- `sanity-pre-apply.json` — резервная копия непосредственно перед импортом.
- `approval.json` — разрешение пользователя на импорт оригиналов.
- `import-plan.json` — сохранённые стандартные Sanity UUID, существующие ID и поля.
  Не удалять и не регенерировать после начала импорта.
- `assets-imported.json`, `applied-groups.json` — изображения и транзакции.
- `sanity-after.json`, `verification.json`, `schema-validation.ndjson` — итоговая сверка.
- `html-live/`, `html-local/` — HTML и результаты проверки отображения.

Команды повторного запуска и проверки сохранены внутри архива в
`migrations/publications/README.md`. Для восстановления из каталога `cms/`:

```sh
tar -xzf backups/completed-migrations-2026-10-27.tar.gz migrations/publications migrations/version-history/context.mjs
```

Для повторного запуска скриптов потребуется вернуть прямую dev-зависимость
`@sanity/uuid@3.0.3`, удалённую после завершения миграции.

Данные уже находятся в production. Изменения кода оставлены для проверки и пуша:
общая папка будущих загрузок публикаций, необязательный alt декоративных обложек,
обработка пустого alt на фронтенде и обновлённые типы. Правила редактора Studio
начнут действовать после его деплоя.
